3. Then, in Figma

  1. Open a design file in the Figma desktop app.
  2. First time only: press ⌘/ (Ctrl+/), choose Import plugin from manifest… and pick tools/figma-layout/figma-plugin/manifest.json.
  3. Press ⌘/ and run Layout Importer. While this page is open its Live capture list shows each capture and, with Import new captures automatically on, brings them in as they finish.
  4. Storybook states land beneath the screens that use those components. Already imported screens? Click Place states for this page in the plugin.
