      Interactive playground

      Imports screens as a clickable version of the app instead of a breakdown: tabs switch, menus open, and Storybook components that match the screen change state when clicked. Everything goes on a Playground page with a note beside each screen saying what to try; the parts it uses go on a Playground components page.
      Uses screens already imported: the selected ones, or every captured screen on this page. To use it: open the Playground page, select a screen, press Present (⌥⌘↵).

      Storybook states

      Import a Storybook capture into this file, and each screen gets the states of the components it shows (buttons, widgets, panels) laid out beneath it, found by component name.
      Uses the selected screens, or every captured screen on this page.

      Only import differences

      Pick a capture to compare with, and imports bring in only what differs from it: changed parts of a screen, or changed Storybook states.
