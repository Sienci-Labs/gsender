machine.command — send something to react to

Fire-and-forget: this resolves when the command has been delivered, not when the machine has finished answering. The response arrives through the parsers below, not as a return value. Try $$ for the settings block, $# for a [PRB:] line.

Settings dump — manifest parser, block mode

Accumulates every $n= line until ok. Status reports that land mid-dump are dropped without closing the block. Send $$ from the console.

machine.query — a command and its whole response

Sends the command and collects every line back until the terminator, the line cap, or the timeout. Idle only — a query while a job is streaming is rejected, because ok would be indistinguishable from the running job's own responses.
